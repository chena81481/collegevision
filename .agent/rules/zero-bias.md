# Zero-Bias Matching Algorithms

## Rule
All university matching algorithms, sorting functions, and "Best Match" logic must be strictly **mathematical** and based solely on user-provided inputs.

## Constraints
- **Unbiased Logic**: Matching must rely on objective metrics:
  - **Financials**: Budget vs. Total Fee, ROI Multiplier (Avg CTC / Total Fee).
  - **Temporal**: Course Duration, Start Dates, Application Timelines.
  - **Eligibility**: Academic scores vs. Admission requirements.
- **No Manual Overrides**: Hardcoded "promoted" or "partner" boosts that bypass mathematical scores are strictly prohibited.
- **Transparency**: The logic for a "Match Score" should be explainable through weights and data points, not arbitrary AI "vibes."
